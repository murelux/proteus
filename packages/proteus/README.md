# @quill/proteus (Core)

The core library for parsing YAML, JSON, and TOML front matter from Markdown files.

## Features
- **Fast**: Powered by Rust WASM.
- **Ecumenical**: Supports YAML 1.2, JSON, and TOML.
- **Edge-ready**: Optimized for Bun, Deno, and Cloudflare Workers.
- **Validated**: Built-in support for Standard Schema (Valibot, Zod v4, etc.).

## Installation
```bash
bun add proteus
```
